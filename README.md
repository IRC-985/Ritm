# Ритм-тренажёр

Приложение для тренировки чувства ритма: «Повтори за мной», «Запиши ритм» (карточками), «Запрещённый ритм».
Само приложение — файл `www/index.html`. Остальное — обёртка, чтобы получить APK для Android.

## Вариант 1. APK без установки чего-либо (через GitHub)

1. Зарегистрируйтесь на github.com и создайте новый репозиторий (кнопка **New**).
2. Нажмите **uploading an existing file** и перетащите туда всё содержимое этой папки,
   включая скрытую папку `.github` (если не перетаскивается — создайте файл
   `.github/workflows/build-apk.yml` вручную через **Add file → Create new file** и вставьте текст).
3. Откройте вкладку **Actions** — сборка «Сборка APK» запустится сама (или нажмите **Run workflow**).
4. Через 5–8 минут откройте завершённый запуск, внизу в разделе **Artifacts** скачайте `ritm-trener-apk`.
5. Распакуйте zip, перекиньте `app-debug.apk` на телефон и установите
   (Android попросит разрешить установку из неизвестных источников).

## Вариант 2. Android Studio

```
npm install
npx cap add android
npx cap open android
```
В Android Studio: **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.

## Вариант 3. Без APK (PWA)

Выложите папку `www` на любой хостинг с https (например, GitHub Pages: Settings → Pages).
Откройте адрес в Chrome на телефоне → меню → «Добавить на главный экран». Работает офлайн.

## Изменения
Правите `www/index.html` → загружаете в репозиторий → GitHub пересобирает APK автоматически.
