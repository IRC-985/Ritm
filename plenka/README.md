# Плёнка

Симуляция фотоплёнки для RAW-файлов на Windows и Android. Это не набор пресетов и кривых: снимок проходит тот же физический путь, что и кадр на настоящей плёнке.

1. **Экспонирование.** По каждому пикселю восстанавливается спектр света. Затем считается, сколько света «увидел» каждый из трёх слоёв эмульсии: используются реальные кривые спектральной чувствительности из техпаспортов Kodak и Fuji.
2. **Рассеяние и ореол.** Свет рассеивается в эмульсии и отражается от основы плёнки, поэтому вокруг ярких мест появляется красноватое свечение (халяция). Размер эффекта задаётся в микронах и зависит от формата плёнки.
3. **Проявка.** Работают характеристические кривые каждого слоя, межслойные DIR-эффекты (дают цвет и резкость краёв) и зерно. Зерно — это статистическая модель частиц: его сила зависит от плотности, у каждого подслоя оно своё.
4. **Печать.** Это для негативов. Свет лампы увеличителя проходит через спектральные плотности красителей негатива и цветные фильтры (в единицах CC), а затем засвечивает бумагу. Нейтральная фильтрация подбирается автоматически, как это делал печатник.
5. **Просмотр.** Красители слайда или отпечатка рассматриваются при свете лайтбокса или проектора. Результат переводится в sRGB или Display P3.

## Плёнки

- **Слайды:** Kodachrome 64, Kodachrome 25≈, Ektachrome E100, Velvia 100, Velvia 50≈, Provia 100F, Agfa CT Precisa≈
- **Негативы:** Kodak Gold 200, UltraMax 400, Portra 160/400/800, Ektar 100, Fuji Superia 200 (C200), Superia X-TRA 400, Pro 400H, Konica Centuria 400≈, Agfa Vista 200≈
- **Чёрно-белые≈:** Tri-X 400, HP5 Plus, FP4 Plus, T-Max 100, Delta 3200. Печатаются на бумаге Multigrade, градация задаётся настройкой.
- **Кино:** Vision3 50D/250D/200T/500T, печать на 2383
- **Бумаги:** Fuji Crystal Archive (минилаб Frontier), Kodak Supra/Ultra/Portra/Premier Endura, Ektacolor Edge

Знак «≈» означает приближение. Для этих плёнок опубликованных спектральных данных нет, поэтому профиль построен из ближайшей родственной плёнки с поправками. Остальные профили — оцифрованные техпаспорта проекта [spektrafilm](https://github.com/andreavolpato/spektrafilm) (Andrea Volpato, лицензия CC BY-SA 4.0).

## Скачать

Готовые сборки выкладываются в **Releases** репозитория с тегом `plenka-v…`:

- `plenka.apk` — для Android;
- `Plenka-setup.exe` — установщик для Windows;
- `Plenka-portable.exe` — версия для Windows, которая запускается без установки.

Сборку делает GitHub Actions (`.github/workflows/plenka.yml`) при каждом изменении в папке `plenka/`.

## Как устроено

| Часть | Где |
|---|---|
| Спектральная модель (таблицы, калибровка печати) | `src/engine/spectral.js` |
| Конвейер на видеокарте (WebGL2) | `src/engine/pipeline.js`, `src/engine/shaders.js` |
| Декодер RAW: LibRaw 0.22, собранный в WebAssembly без потоков | `native/`, `public/wasm/` |
| Данные плёнок | `public/data/`, генерирует `tools/bake.py` |
| Интерфейс | `src/main.js`, `src/ui.js` |
| Экспорт тайлами в полном разрешении (JPEG / TIFF 16 бит) | `src/export.js` |
| Обёртки | `electron/` (Windows), Capacitor (Android) |

## Запуск при разработке

```
npm install
npm run dev          # в браузере: http://127.0.0.1:5173
npm run electron     # как приложение Windows/Linux
```

Чтобы пересобрать декодер RAW, нужен emsdk: `source emsdk_env.sh && npm run wasm`.

Чтобы пересоздать данные плёнок, нужен клон spektrafilm: `python tools/bake.py путь/к/spektrafilm/src/spektrafilm`.

## Ограничения

- Nikon High Efficiency NEF (HE / HE*) открытая LibRaw не читает. Снимайте в Lossless compressed.
- На телефоне файлы на 60–100 Мп в полном размере могут не поместиться в память. В этом случае выберите «Размер → Половина».
- Скорость зависит от видеокарты. Просмотр пересчитывается на лету, а сохранение 24 Мп на обычной видеокарте занимает секунды.
